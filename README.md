# Daymark Todo

A small React todo app with a demo login and browser-based storage.

## Run locally

Install the dependencies and start the Vite development server:

```sh
npm install
npm run dev
```

## Demo account

- Email: `student@example.com`
- Password: `password123`

Todos are saved in the browser's `localStorage`. The demo sign-in lasts for the current browser session.
